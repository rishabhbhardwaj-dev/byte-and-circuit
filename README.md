✦ About the Project
BYTE & CIRCUIT is an experimental visual tech-news experience that reimagines a digital publication through the lens of a 1990s print magazine.

The project focuses on editorial typography, unconventional layouts, tactile paper textures, layered visual effects, and immersive interactions—without relying on frameworks or build tools.

Think print magazine energy, rebuilt for the web.

✨ Features
<table> <tr> <td width="50%">

📰 Editorial Typography
Uses Playfair Display for expressive headlines and IBM Plex Mono for a technical editorial feel.

🧩 Dynamic Magazine Grid
Articles use varying multi-column layouts such as 2fr / 1fr, 3fr / 2fr, and three-column compositions.

📐 Print Overflow Headlines
Large masthead typography intentionally extends beyond the viewport for an authentic print-inspired composition.

📖 Page-Turn Transitions
Sections transition using CSS 3D perspective effects to create a subtle page-turning experience.

🔢 Interactive Table of Contents
A numbered 01–06 navigation system with hover-responsive typography and magazine-style interaction.

</td> <td width="50%">

🟤 Sepia + Noise Treatment
Images receive subtle sepia filtering and layered SVG fractal noise for a vintage editorial appearance.

📄 Paper Texture Overlay
A fixed texture layer adds visual grain across the entire experience.

🔠 Drop Caps
Article introductions use stylized first-letter treatments inspired by traditional editorial layouts.

💬 Pull Quotes
Important editorial statements are highlighted through accent borders and italic typography.

📱 Responsive Design
The multi-column experience adapts smoothly into a readable single-column layout on smaller screens.

</td> </tr> </table>

🎯 Design Direction
The goal of this project was to move away from the predictable structure of modern websites and explore a more editorial, expressive, and tactile web experience.

The design draws inspiration from:
